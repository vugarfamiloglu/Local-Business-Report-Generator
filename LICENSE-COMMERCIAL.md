This document describes a **separate, optional, paid commercial offering** for
Tally. It exists alongside the Apache License 2.0 (see the `LICENSE` file) and
does not modify or override it.

## Read this first

Tally is open source under Apache License 2.0. That license already grants
every user — including organisations of any size — the right to:

- run the software for any purpose, including commercial use,
- modify and adapt the source code,
- redistribute it (modified or not),
- include it in proprietary products and services.

**You do not need a paid license to use Tally commercially.** The Apache 2.0
license is sufficient for nearly every scenario.

This Commercial License is a separate offering for the small group of
organisations whose legal, procurement, or compliance teams require formal
terms that open-source licenses cannot provide.

## What the Commercial License adds

If you purchase a Commercial License from the author, you receive — for the
duration of the agreement — one or more of the following, depending on the
tier you select:

### 1. Attribution waiver for white-label deployments

Apache 2.0 requires that copyright notices and the `NOTICE` file (when
present) be preserved in distributed copies and derivative works. The
Commercial License waives those preservation requirements for a single
named organisation, so the software can be redeployed under that
organisation's own branding without visible upstream attribution.

### 2. Limited warranty + IP indemnification

Apache 2.0 ships the software "AS IS" with no warranty. The Commercial
License adds:

- a limited warranty that the software, as delivered, conforms to the
  documentation under normal operating conditions;
- indemnification against third-party intellectual-property claims that
  arise from the upstream source code itself (not from the buyer's
  modifications or third-party plugins).

### 3. Priority support

A direct support channel to the project author with a guaranteed response
window:

- critical incidents (production down, security): one working day
- major bugs: three working days
- feature requests + integration questions: five working days

Communication is over email, scheduled video calls, or a shared issue
tracker, at the buyer's preference.

### 4. Custom integration assistance

Help integrating Tally with proprietary systems — internal CRMs, BI
dashboards, accounting back-ends, or report-distribution pipelines that
aren't covered by the open-source codebase.

## What the Commercial License does NOT do

To avoid any confusion:

- It does **not** make Tally closed source. The public repository remains
  open under Apache 2.0 indefinitely.
- It does **not** restrict any other party's rights under Apache 2.0.
  Other organisations using the open-source release retain all rights
  granted by Apache 2.0.
- It does **not** cover forks or third-party modifications. Those remain
  governed by Apache 2.0 unless the modifying party separately negotiates
  their own commercial terms with the author.
- It does **not** transfer ownership of the codebase. The author remains
  the sole copyright holder of the upstream project.

## Governing principle

The presence of this Commercial License does not signal that commercial
use of Tally is restricted. It is not. Apache 2.0 grants every commercial
right one would reasonably want.

This document exists solely so that buyers whose procurement processes
require a signed commercial agreement have one to sign — and so that
the author can offer warranty + support tiers to organisations that
want them.

If you are uncertain whether you need this license, the answer is
almost certainly **no**. Use the project freely under Apache 2.0.
